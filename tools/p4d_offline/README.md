# P4d 离线安全状态模型

运行：在仓库根目录执行 python3 tools/p4d_offline/test_arm_safety_model.py。

该脚本只验证 P4d 设计文档中的策略预期：上电互锁、100 ms 候选命令租约、序号/会话防重放、输入拒绝、反馈故障锁存、远控切换和人工复位。界限数组是模型夹具，不是实机关节限位。脚本没有导入 ROS、串口、STM32/HAL 或电机代码，测试通过不能作为固件或整机安全验收。

当前实现行为仍以 P4c 审计为准。测试用模型表达的目标策略尚未在生产驱动或固件实现；实施前须先确认 docs/p4d/arm-safety-remediation-design.md 中列出的扭矩、急停、故障轴和人工使能决策。
