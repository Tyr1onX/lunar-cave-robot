# 硬件负责人确认清单

目的：在讨论 STM32 安全修改和无动力联调前，记录“源码写了什么”与“实体设备实际是什么”。请负责人逐项填写实物版本、接线和可验证证据。固件仓库快照不代表控制板当前正在运行的固件。

| 项目 | 当前源码可确认的信息 | 硬件负责人需确认/填写 |
| --- | --- | --- |
| 底盘 MCU/板卡 | CubeMX 工程以 STM32H723VGT6 为目标 | 实际板卡型号、PCB 版本/修订、晶振与电源版本 |

## 评审前需提供的材料

- 两块控制板的正反面照片、PCB 版本与丝印。
- 六台底盘电机及七轴机械臂/夹爪的铭牌照片和驱动器参数导出。
- 电源树、接线表、CAN 拓扑/速率/终端、UART 与 USB 接线。
- 独立急停原理图，以及急停动作对电机电源和机械臂负载的影响说明。
- 电机制动/失能说明书或经负责人确认的测试记录；机械臂失电下坠防护方法。
- 当前实体固件的版本来源。仅凭 Git 当前源码不能认定它就是已烧录固件。
- 机械臂 XRobot 产品生成配置、模块清单、锁文件和工具版本，见 [XRobot 构建恢复记录](XROBOT_ARM_BUILD_RECOVERY.md)。

本清单只记录静态源码配置和待确认事项，不授权连接实体控制器、烧录、使能驱动器或执行运动。软件 DISARMED/FAULT_LATCHED 以及 relax/disable 名称均不能作为实体急停、制动或负载保持的证明。
