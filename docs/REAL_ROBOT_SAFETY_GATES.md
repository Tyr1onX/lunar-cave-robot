# 实体机器人联调前安全门槛

本文件将离线通过与真实运动许可分开。P7/P8 的 ROS、Nav2 和 PTY 结果不证明实体制动、驱动器或机构安全。以下未完成前，不允许执行底盘或机械臂运动测试。

## S0：任何带电运动前必须关闭

1. **控制链路失联行为**：P5b 的 14 字节底盘帧只有主机到控制器的单向速度，没有 STM32 回执、命令序号或物理速度/制动状态。主机 `HOST_WRITE_OK` 只代表本机 TTY 写入成功。需定义 MCU 通信看门狗、速度指令租约、超时停车策略、故障锁存和实际停止状态反馈；测量停车延迟/距离前不得让底盘离地或落地运动。
2. **机械臂取消与旧命令防护**：P4f 的任务 ID、epoch、单调序号只存在 ROS 消息元数据中，现有 46 字节 STM32 帧不传递这些字段。MCU 可能仍在执行已送达的旧目标。固件后续需实现任务代际、序号去重、明确取消确认、队列/插值缓存清理、取消后不接受旧代际命令、反馈超时锁存和重启后 DISARMED。
3. **真正停止与急停**：定义并验证驱动器失联、主机断电、MCU 重启、总线断线和急停时的电机使能、制动、保持扭矩和机械臂防坠行为。不得把 ROS Action cancel、上游取消 ACK、串口写 0 或协议使能位清零当成实体急停或制动确认。急停必须在运动前由独立硬件链路验证。
4. **限位与负载**：核对每关节软/硬限位、方向、零位、减速比、电流/力矩限制、工具负载、夹爪夹力和碰撞风险。先在机械臂可靠支撑、人员撤离、低能量/低速条件下，由安全负责人验证单关节和断电测试。
5. **人工恢复互锁**：复位、重新使能及退出故障锁存必须有明确操作者身份、现场观察和单独动作。禁止启动时自动 reset/enable，禁止故障恢复后恢复旧任务。

## S1：完整自主任务前必须验证

- MID-360 实际地址、路由接口、UDP 双向端口、稳定原始点云和 IMU 主题；本轮未开驱动、未接雷达。
- 雷达点云/IMU 源时间戳、时钟来源、时间跳变和频率。首次静态采集不要求 Point-LIO；但进入自主导航前必须选择并验收定位方案。
- 相机/目标识别的真实图像与标定、相机至机械臂基座外参、抓取坐标转换和工作空间边界。P6 的目标检测是离线合成数据。
- 编码器/里程计尺度、轮径、轮距、打滑、IMU 朝向、地图定位，以及 `map → odom → base_* → livox_frame/camera` TF 的方向与单一发布者。P7 的地图、雷达、里程计和 TF 是仿真节点生成的。
- 核对实机 Nav2 `base_frame`、P7 使用的 `base_link`、实际 odom topic 与驱动器命名空间；不要靠 remap 隐藏 frame 或 topic 的语义错误。
- 验收 MCU/驱动实际反馈与命令对应关系，P4e 状态、反馈超时、继电器/制动状态和故障锁存由控制器侧信号支撑，而非由模拟器/主机回环代替。

## S2：工程化改进

- P4f 仍把 task/epoch/sequence 放在 `sensor_msgs/JointState.header.frame_id` 字符串里。ROS 侧过滤可用，但字段语义非标准，建议定义独立的带类型 `ArmTrajectoryCommand`/`ArmTrajectoryCancel` 消息，明确命令代际、序号、有效期、取消结果和控制器停止反馈。
- 将 P5b 字符串健康状态迁移到 `diagnostic_msgs` 或专用状态消息，增加序列、主机接收时间、端口状态和错误计数；仍不能代替 MCU 应答与测得的物理状态。
- 为底盘 MCU 和机械臂 MCU 分别做协议兼容与故障注入验证；P8 保持现有 14/46 字节格式，未改固件。

## 分阶段实机验证建议

1. 桌面/断电审查：电气图、急停链路、制动器、驱动器故障状态、协议实现与风险分析签字。
2. **仅 MID-360 静态采集**：按 [MID-360 独立验收流程](MID360_STATIC_ACCEPTANCE.md)，不启动整机 bringup；通过后保存脱敏 bag 和指标。
3. 传感器标定与离线回放：验证 IMU 时间、雷达外参、相机外参、坐标树和目标点变换。
4. 无执行器能量的 HIL：接控制器但保持电机硬件断开，验证协议、心跳/租约、序号防重放、取消/重连、故障锁存与人工恢复。
5. 机械臂有支撑、无载荷、限速限力：由现场安全负责人执行单关节、急停、断电、防坠与限位试验；明确实测停止距离/状态。
6. 底盘架空低速测试：测量命令中断与急停停车响应；只有 MCU 停车反馈及硬件急停均通过后，才做有地面约束的短距离移动。
7. 分开验证定位与 Nav2、机械臂独立拾放、底盘与机械臂互锁，最后才批准带真实目标的任务级闭环；每一步设置人工观察者、物理急停、速度/区域限制和失败退出条件。

本路线不授权本轮执行任何实体运动或硬件控制器连接。
