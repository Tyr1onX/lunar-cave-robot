## 新克隆后的环境恢复

1. 用有权限的 GitHub 账户克隆集成分支：

~~~bash
git clone --single-branch --branch archive/unified-engineering-assets-p5b https://github.com/Tyr1onX/lunar-cave-robot.git
cd lunar-cave-robot
~~~

2. 使用 Ubuntu 22.04 和 ROS 2 Humble。先安装 colcon、rosdep、python3-yaml 和仓库说明列出的 MoveIt 2/Nav2/点云依赖。tzb_ws 与 Nav2_rea_ws 分开构建、分开 source，不要在一个终端叠加两个 install/setup.bash。
3. 用 Python 3 可先运行无 ROS 的 P5a 模型测试：

~~~bash
python3 tools/p5a_offline/test_chassis_control_path.py
~~~

4. 在 Nav2_rea_ws 中按 docs/p5b/run-offline-validation.md 构建 chassis_serial_bridge，再运行 tools/p5b_validate_configuration.py 和 tools/p5b_pty_ros2_integration.py。PTY 集成测试使用模拟串口，不要填入实体设备路径。P4c PTY 测试要求单独构建/准备 P4b ROS 工作空间，运行方式见 docs/P4c_control_safety_audit.md。
5. Orbbec/Livox SDK、YOLO 权重、RGB-D bag、私有地图和两套 STM32 固件均须另行取得权利人许可；本分支没有可编译的 STM32 固件源码，不要从未经授权的 ZIP 补入。
