## 新克隆后的环境恢复

1. 使用有权访问私有仓库的 GitHub 账户，克隆指定分支：

       git clone --single-branch --branch archive/unified-engineering-assets https://github.com/Tyr1onX/lunar-cave-robot.git
       cd lunar-cave-robot

2. ROS 工作空间恢复使用 Ubuntu 22.04 和 ROS 2 Humble；安装 colcon、rosdep 及 README/架构文档列出的依赖。按 README 的独立终端命令分别构建 tzb_ws 和 Nav2_rea_ws，不要在同一个终端叠加两个 install/setup.bash。
3. 可先用 Python 3 运行独立底盘模型测试：

       python3 tools/p5a_offline/test_chassis_control_path.py

4. 根据 RELEASE_AUDIT.md 单独获取并授权缺失的 Orbbec/Livox SDK、MoveIt/Nav2 等依赖；未获授权的 SDK、模型与传感器数据不要复制进仓库。
5. 当前分支没有可编译的 STM32 固件源码。获得来源与再分发授权后，才补齐 firmware/arm 和 firmware/chassis 的过滤后源码与构建依赖清单；本次未烧录或部署任何设备。
