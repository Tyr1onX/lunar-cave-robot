# 六轮差速底盘串口通信协议

本文档对应当前工程代码，描述上位机通过 `USART1` 向六轮差速底盘发送运动指令的协议。

## 1. 串口配置

| 项目 | 配置 |
| --- | --- |
| 串口 | `USART1` |
| TX | `PA9` |
| RX | `PA10` |
| 波特率 | `115200 bit/s` |
| 数据位 | `8 bit` |
| 停止位 | `1 bit` |
| 校验位 | 无 |
| 流控制 | 无 |

底盘使用 DMA + 空闲中断接收串口数据。上位机应周期性发送完整指令帧，建议发送周期不超过 `100 ms`。

## 2. 固定帧格式

每帧固定 `14` 字节：

| 字节位置 | 长度 | 字段 | 类型 | 单位/说明 |
| ---: | ---: | --- | --- | --- |
| 0 | 1 | 帧头 | `uint8_t` | 固定 `0xA5` |
| 1～4 | 4 | `VX` | IEEE 754 `float32`，小端 | 车体线速度，单位 `m/s` |
| 5～8 | 4 | `VY` | IEEE 754 `float32`，小端 | 横向速度/特殊功能字段 |
| 9～12 | 4 | `VZ` | IEEE 754 `float32`，小端 | 偏航角速度，单位 `rad/s` |
| 13 | 1 | 帧尾 | `uint8_t` | 固定 `0x4A` |

帧结构：

```text
A5 | VX[4] | VY[4] | VZ[4] | 4A
```

多字节浮点数使用小端字节序。例如：

```text
1.0f  -> 00 00 80 3F
0.05f -> CD CC 4C 3D
```

接收端会检查帧头、帧尾以及三个浮点数是否为有限值。非法帧会被丢弃。

## 3. 控制权限：CH8 三段拨杆

UART5 接收 SBUS 遥控器，CH8 为底盘总控制源选择开关。当前按照 PWM 值判定：

| CH8 PWM 值 | 拨杆位置 | 底盘状态 | USART1 | SBUS 遥控 |
| ---: | --- | --- | --- | --- |
| `< 1300` | 下拨 | 失能、立即停车 | 屏蔽 | 屏蔽运动控制 |
| `1300～1700` | 中置 | 串口控制 | 接收 | 屏蔽运动控制 |
| `> 1700` | 上拨 | 遥控控制 | 屏蔽 | 接收 |

这里的“屏蔽”指软件控制入口屏蔽。底层 UART DMA 仍保持运行，以便持续读取 SBUS 的 CH8 状态；被屏蔽来源的合法帧会直接丢弃，不会写入底盘运动指令。

### 3.1 失能模式：CH8 下拨

- USART1 接收的运动帧全部丢弃。
- 已保存的串口或遥控速度指令被清除。
- 底盘线速度和偏航角速度设为 `0`。
- 电机周期性收到 `V_des=0、Kp=0、Kd=0、T_ff=0` 的 MIT 指令。
- 电机不会继续执行上一帧的速度指令。

### 3.2 串口模式：CH8 中置

- 只允许 USART1 指令控制底盘。
- SBUS 的 CH1、CH3 摇杆值不会发布到底盘。
- 如果没有持续收到新的合法串口运动帧，超过 `200 ms` 后底盘自动停车。

### 3.3 遥控模式：CH8 上拨

- 只允许 UART5 SBUS 遥控器控制底盘。
- USART1 合法帧会被直接过滤。
- SBUS 遥控信号掉线超过 `100 ms` 后，底盘失能并停车。

## 4. 普通速度指令

普通运动帧含义如下：

```text
VX = 目标前进/后退线速度
VY = 0.0f
VZ = 目标偏航角速度
```

由于底盘为六轮差速结构，普通模式下 `VY` 不参与横向运动控制，建议始终发送 `0.0f`。

底盘控制程序会对指令进行限幅：

| 参数 | 当前值 |
| --- | ---: |
| `VX` 最大值 | `±0.6 m/s` |
| `VZ` 最大值 | `±1.5 rad/s` |
| 串口指令超时 | `200 ms` |

当前坐标约定：

- `VX > 0`：车体前进
- `VX < 0`：车体后退
- `VZ > 0`：逆时针旋转
- `VZ < 0`：顺时针旋转

### 4.1 低速直行示例

发送 `VX=0.05 m/s，VY=0，VZ=0`：

```text
A5 CD CC 4C 3D 00 00 00 00 00 00 00 00 4A
```

### 4.2 停车示例

发送 `VX=0，VY=0，VZ=0`：

```text
A5 00 00 00 00 00 00 00 00 00 00 00 00 4A
```

## 5. 航向锁定指令

串口模式下，使用以下特殊帧进入航向锁定：

```text
VX = 0.0f
VY = 1.0f
VZ = 0.0f
```

完整帧：

```text
A5 00 00 00 00 00 00 80 3F 00 00 00 00 4A
```

进入锁定后：

1. 记录进入时的当前连续偏航角。
2. 停止车体前后运动。
3. 使用 IMU 偏航角反馈保持目标角度。
4. 受到扰动后，通过差速控制回到目标角度。

发送任意普通速度帧即可退出航向锁定。发送停车帧会退出锁定并保持停止。

## 6. 帧发送与超时要求

- 串口运动指令必须周期性发送。
- 连续 `200 ms` 没有新的合法串口指令时，底盘自动清零速度并停止。
- 切换到 CH8 遥控模式时，串口帧会被过滤，不会覆盖遥控指令。
- 切换到 CH8 失能模式时，串口帧会被过滤，已有速度指令会被清零。
- 失能或切换控制源时，不需要等待下一帧串口数据即可停车。
