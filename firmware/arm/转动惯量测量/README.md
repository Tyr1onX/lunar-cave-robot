# 关节转动惯量辨识（离线）

从调试器导出的 CSV 日志里辨识各关节的等效转动惯量，结果写入固件的
`RoboArm_N::kJ_scale / kJ_offset`（惯量前馈的对角项）。

## 1. 用法

```powershell
cd 转动惯量测量
g++ -std=c++17 -O2 -Wall identify_inertia.cpp -o identify_inertia.exe

# 被测关节会自动识别（哪个关节同时有 pos/vel/torque 列）
.\identify_inertia.exe J5.csv -g -o report_j5.txt
.\identify_inertia.exe 'J2 J3.csv' 3 -g -o report_j3.txt   # 一个文件里有两个关节时用第 2 个参数指定
```

| 参数 | 说明 |
|---|---|
| `-g` | **几乎总是要加**：逐样本扣掉固件下发的重力前馈 `tg`。不加的话重力梯度会按 `1/ω²` 串进 J |
| `-k` | 回归里额外加 θ 列（只有多音/扫频激励才有意义，单频正弦下 θ 与 α 严格共线） |
| `-o 文件` | 报告写进文件。**别用 PowerShell `>` 重定向**（会写成 UTF-16 乱码） |

报告里每段都会给出 `J ± sd`、模型值 M、惯性项占扭矩的百分比、`corr(a,w)`，
以及 `J is identifiable` / `J NOT identifiable` 的结论。

## 2. 辨识模型

单轴（其余轴锁住）：

```
tau = J*alpha + B*omega + Fc*sgn(omega) + b
```

- `alpha` 由单圈角度 **unwrap 后**、按真实时间戳做 ±8 点局部二次拟合得到；
  **不要**用 `vel` 列直接微分（电机上报速度已被滤波，算出来 J≈0）。
- 逐段最小二乘 + 全局最小二乘（每段一个 J，B/Fc/b 共享）交叉验证。
- 可用段筛选：惯性项占扭矩 > 25%、摩擦项 `B*rmsW` < 80% 的扭矩。
  摩擦占主导的段会给出假的大 J（曾出现 0.49/0.55 vs 真值 0.21）。

## 3. 数据导出要求

- 被测关节必须有 **`pos` / `vel` / `torque`** 三列；其余关节至少有 `pos`（算姿态 + 判断是否锁死）。
- 每段 ≥ 5 个整周期、≥200 Hz 均匀采样、幅值尽量大（`rms(alpha)` ≥ 2 rad/s² 才好用）。
- **其它关节要真的锁住**：现在 `kp_pos=0`、`kq_pos` 只有 j2 有值，j3~j7 靠 `tg` 撑，
  被测轴一动别的轴会垂（曾出现 j5 跟着 j6 动了 1.1 rad）。
- 顺手多录几段**不同姿态的静止保持**——静止力矩直接就是重力矩，用来校核质量模型。

### 调试器导出的三个坑（脚本已自动处理，但导出时最好清一下）

1. 列名带 ` @ 0x20000940` 后缀；`J2 J3.csv` 里 `j3_left.pos` 重复导出两次。**有表头时脚本绝不再按位置猜列**。
2. 时间戳跳变（`J5.csv` 有 2 处，最差 −6.19 s，日志是拼接的）→ 拟合窗口不跨跳变点。
3. 日志开头所有关节读 0（CAN 反馈还没到）→ 0→真实姿态的台阶会造成假激励（`rmsA` 冲到 50）。

## 4. 结果汇总（kg·m²）

| 关节 | 实测 | 同姿态模型 M | 结论 |
|---|---|---|---|
| j1 | 折叠 0.245~0.328；伸展 0.435~1.287 | 0.062~0.352 | **3.30·M + 0.109**（12 点，R²=0.979） |
| j2 | 0.22~0.29 | 0.24~0.36 | 模型可用 |
| j3 | 0.218 | 0.1881 | 模型低 16% |
| j4 | 未测 | — | — |
| j5 | 0.011（另一 j6 姿态 0.005） | 0.0091 | 模型可用 |
| j6 | ~0（不可辨识） | 0 | 与模型一致 |
| j7 | 未测 | 0 | — |

**重力模型的验证**（静止段）：j2 在 23 N·m 量程上偏差 ±1.07 N·m，j5 在 0.85 N·m 量程上偏差 ±0.12 N·m
→ 各杆的 `m·r` 是对的，**不要整体缩放 `kMass`**。

## 5. 落到固件

1. `others/inc/obj/roboarm.hpp`：填 `kJ_scale[] / kJ_offset[]`（注释里有每项的来源与置信度）。
2. `others/src/obj/roboarm_kinematics.cpp::AccumulateInertia()`：循环末尾按
   `M_ii = Σ_{k>=i} m_k·d_k²`（闭式）算模型对角项，再用 `kJ_scale/kJ_offset` 换成实测值，
   把差值补到 `td` 上。非对角/科氏项仍来自模型。
3. 改完请重新编译；闭式公式的正确性可用脚本交叉验证：
   报告里 `model: M=x (closed form y)` 的 x、y 必须相等。
